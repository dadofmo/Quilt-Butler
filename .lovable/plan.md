# Add the Album Cross pattern

Build Album Cross as a new four-fabric pattern, matching the supplied block exactly and supporting the full quilt-planning flow.

## Pattern construction

- Draft the block as a 3×3 grid of equal finished units.
- Use Fabric A for the four solid edge-centre squares.
- Use Fabric B for the solid centre square and the inner background area of each corner unit.
- Build each corner as one large half-square-triangle split between Fabrics B and C, then add a Fabric D square to the corner nearest the block centre using a stitch-and-flip corner. Rotate the four corner units so the Fabric C triangles point toward the four outside corners and the Fabric D squares form the four corners of the central cross.
- Keep all shapes flush, with no decorative seam outlines.

- Use the shared fabric tokens and photo-fill behavior so uploaded fabric images render consistently everywhere.

## Cutting math and instructions

- Calculate exact quantities from the real block count and chosen block size.
- Cut four Fabric A edge squares and one Fabric B centre square per block.
- Create four oversized Fabric B/C half-square-triangle units per block, then add one Fabric D stitch-and-flip square to the inner corner of each unit; explain trimming, orientation, pressing, and 3×3 row assembly clearly.
- Route every cut through the existing square/strip yardage helpers and include optional sashing and border calculations.
